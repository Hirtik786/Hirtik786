- **Build for real users:** Start with a problem and design around the people experiencing it.
- **Understand the fundamentals:** Learn why a solution works, not only how to assemble it.
- **Write maintainable software:** Keep code, documentation, and project structure understandable.

- **Keep learning:** Improve through feedback, iteration, and hands-on practice.
